# Hero assets

Place Marvel Rivals hero icons here as optimized WebP files. The current roster expects these filenames:

`luna-snow.webp`, `magneto.webp`, `psylocke.webp`, `mantis.webp`, `doctor-strange.webp`, `hela.webp`, `groot.webp`, `spider-man.webp`, `rocket-raccoon.webp`, `magik.webp`, `star-lord.webp`, and `punisher.webp`.

Missing files automatically fall back to the colored initials already visible in the app.
